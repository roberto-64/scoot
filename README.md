# Scoot

A private iOS app to log fuel, maintenance, expenses and Italian deadlines (RCA, Bollo, Revisione)
for one or more vehicles, with statistics and charts. SwiftUI + SwiftData, iOS 17+, fully local:
no accounts, no backend, no plate or VIN. Italian by default, English switchable.

- **Read first:** `HANDOFF.md` (status, decisions, next steps) and `DESIGN.md` (the locked design rules).
- **Build:** push to GitHub; the **Build IPA** workflow makes an unsigned `.ipa` (see `HANDOFF.md`, section 9).
  The project file is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`.
- **Status:** all files written, not yet compiled. See `HANDOFF.md` (section 6) for the current status and next steps.
- **Design reference:** `docs/design-preview.html` (open in a browser).

Fonts are Apple system fonts. No third-party packages. No secrets in this repository.
